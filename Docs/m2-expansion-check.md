# Проверка расширения M2 в редакторе (для локальной сессии с Unity MCP)

Облачная сессия 04.11.2026 написала Sim (тесты зелёные) и Presentation, но Unity не открывала:
Presentation компилировался только против Unity 2021.3 API с заглушкой Input System. Проверить:

1. Консоль после компиляции: ошибок нет (возможны расхождения API Unity 6).
2. Сцена `Main`, объект `SimRunner`: новые компоненты `GameMenu`, `BuildingPanel`, `RallyView`
   (добавлены в YAML), в `SimRunner` — `_missionsJson` и три карты в `_maps`. Нет «Missing Script».
3. Play → главное меню: «Чёрный Легион», «Логово Серых Существ», «Загрузить», «Выйти».
4. Миссия m2: у штаба один строитель, `Tab` выделяет его, второй `Tab` — камера к нему.
   Строитель строит бур, ленту, завод. Завод без ленты: кнопки серые, «подведите ленту»;
   лента от бура в завод → «Склад: N / 150» растёт, ремонтник производится.
5. ПКМ по земле при выделенном заводе — флажок и пунктир, юниты идут туда; ПКМ по заводу — убрать.
6. Выделить своё здание → «Снести (Del)», шкала сноса, здание темнеет, возврат в уведомлении.
7. Ремонтник сам идёт чинить повреждённое здание и раненого юнита.
8. Убить строителя (Легион) → «вернётся через 0:15», через 15 с он у штаба.
9. Esc (без размещения) → пауза; «Сохранить», «Загрузить» (список), загрузка возвращает ту же партию;
   «Выйти в меню». Esc при размещении здания сначала отменяет размещение.
10. Миссия coop: 2 штаба разного цвета, F1/F2 переключают игрока; карта 128×128 не тормозит
    (туман, рельеф, миникарта). Нейтральные бур/пещера/маяк серо-белые, подсказки при наведении,
    шкала захвата, перекраска после захвата; маяк зажигает огонь и открывает обзор; пещера после
    зачистки стражей и захвата нанимает зверя и плевуна со своего склада. Убить вожака → «Победа!».
11. Уведомления: «Ваши войска атакованы», «Строитель атакован!», «Погиб: …», «Захвачено: …».
12. Загрузка длинного сохранения замораживает кадр на несколько секунд (проматывание ~0,4 мс/тик) — оценить, терпимо ли.
