# Механика: бой юнитов

Статус: **рабочая версия, решение Claude.** Опора — `PLAN.md` M1 («бой»), статы `units.csv` (`damage`, `damage_vs_buildings`, `armor`, `attack_range`, `attack_cooldown_s`, `vision`), формула урона из скилла `add-unit` и `balance-notes.md`, тревога «бур атакован» из `drill.md`. Выбор цели и преследование — по образцу SC2, брат может поправить что угодно.

Бой нужен в M1 для зачистки лагеря крипов (`creep-camp.md`) и защиты буров. Микроконтроль — столп игры, но порог APM должен быть низким (антимотивация 2): юниты сами отвечают на угрозу рядом.

## Допущения

1. Атакуют только юниты; турель — M2.
2. Поведение крипов — `creep-camp.md`; здесь — юниты игроков (и общее: урон, смерть).
3. Атаки с движением (attack-move) нет в M1: обычный приказ «идти» просто идёт.

## A. Поведение

- **Намерение:** уничтожать врагов и их здания, не управляя каждым ударом.
- **Input:** правый клик выделенными юнитами по врагу (юниту или зданию) — «атаковать».
- **Action:** юнит идёт к цели, пока она не окажется в дальности атаки, и бьёт раз в `attack_cooldown_s`. Цель погибла — юнит ищет следующую рядом (как простоя).
- **Простой:** юнит без приказа (кроме рабочих) сам атакует ближайшего врага в пределах своего обзора: сначала юнитов, потом здания; при равном расстоянии — меньший id. Если цель ушла из обзора — бросает её и стоит.
- **Урон:** `урон − броня цели`, не меньше 1. По зданию — `damage_vs_buildings`.
- **Результат:** при HP = 0 юнит или здание уничтожены: груз рабочего, буфер бура, ресурс на ленте пропадают; клетки освобождаются.

## B. Данные

### Состояния юнита в бою

```
Стоит ──(враг в обзоре / приказ «атаковать»)──▶ Идёт к цели ──(в дальности)──▶ Бьёт
  ▲                                                  ▲                          │
  └──(цель ушла из обзора / погибла, врагов нет)─────┴─────(цель отошла)────────┘
```

### Параметры

| Параметр | Значение |
|---|---|
| Дальность | от края до края: для юнита — между окружностями, для здания — до ближайшей клетки |
| Урон | `damage − armor`, минимум 1; по зданиям `damage_vs_buildings − armor` |
| Тревога «здание атаковано» | не чаще раза в 5 с на здание (`rules.csv`, `attack_alarm_cooldown`) |

### Ограничения

- атаковать можно только врага (`Relation.Enemy`); союзника и нейтрала — нет;
- рабочие атакуют только по приказу;
- удары одного тика применяются одновременно: двое, убившие друг друга в один тик, погибают оба.

### Fail cases

- цель погибла по пути — юнит ищет новую рядом или стоит;
- приказ атаковать союзника — отклонён.

## C. Проверка

### Given / When / Then

| # | Дано | Когда | Тогда |
|---|---|---|---|
| 1 | Пехотинец A (урон 12) рядом с малым крипом (80 HP, броня 0) | A приказывает атаковать | Крип теряет 12 HP каждые 0,8 с и погибает после 7-го удара |
| 2 | Пехотинец A стоит, в 4 клетках появляется враг | — | Пехотинец сам идёт и бьёт ближайшего |
| 3 | Враг бьёт бур A | — | A и союзник B получают событие «здание атаковано»; повторно — не раньше чем через 5 с |

### Edge cases

| Ситуация | Решение |
|---|---|
| Урон меньше брони | 1 HP за удар |
| Два юнита убивают друг друга в один тик | Оба погибают |
| Цель ушла за предел обзора простаивающего юнита | Бросает цель |
| Рабочий стоит рядом с врагом | Не атакует сам |

### Что нужно от UI и арта

- курсор «атаковать» над врагом; полоска HP над повреждёнными;
- видно удар (вспышка/линия), гибель (исчезновение с эффектом);
- тревога и метка на миникарте «здание атаковано» — владельцу и союзникам.

## Приложение: перевод в единицы Sim

Дальность, обзор, радиусы — милли-клетки; перезарядка — тики (`attack_cooldown_ticks`). Удары копятся за тик и применяются после хода всех юнитов в порядке id атакующего. Каждый применённый удар — событие `HitLanded` (кто, кого, сколько): по нему UI показывает вспышку и линию удара. Тесты — `Game.Sim.Tests/Mechanics/CombatTests.cs`.
