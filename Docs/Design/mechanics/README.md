# Спеки механик — указатель

Одна механика — один файл по шаблону `_TEMPLATE.md`: Допущения → A. Поведение → B. Данные → C. Проверка. Строки Given/When/Then и Edge cases один к одному стали тестами в `Game.Sim.Tests/Mechanics/`; имя теста начинается с номера строки (`GWT1_…`, `Edge_…`).

Все спеки ниже реализованы. Братом утверждена одна — `drill.md`. Остальные — рабочие версии: их написал Claude по ответам брата и просьбам Сергея, решения с номерами лежат в `../decisions.md`, и брат может поправить любое.

## Что читать вместе

Некоторые механики описаны несколькими спеками: базовая плюс те, что её расширили. Базовая спека при этом поправлена и ссылается на расширения.

- **Как идёт ресурс:** `drill.md` → `conveyors.md` → `belt-merge.md` → `factory.md` (склад завода) → `factory-auto.md` (проходной склад).
- **Как игрок рисует ленты:** `conveyors.md` → `smart-line.md` → `relay-and-demolish.md`.
- **Как игрок строит:** `construction.md` → `builder.md` → `builder-beam.md` → `build-mode.md` → `order-queue.md`.
- **Что бывает с разрушенным и лишним:** `demolish.md` → `relay-and-demolish.md` → `rebuild-ghosts.md`.
- **Как армия воюет:** `combat.md` → `attack-move.md` → `heights.md` (преимущество высоты).

## Как вести спеки

1. **Спека описывает то, как механика работает сейчас.** Если новая спека или решение меняет старую механику, текст старой спеки правится на месте — в том же разделе, где стояло прежнее правило, с номером решения в скобках. Раздел «веха N: что изменилось» в конец не дописывается: читатель не должен накладывать правки в уме. Что было раньше, хранят git и `../decisions.md`.
2. **Номера строк проверки не меняются.** На них стоят имена тестов. Новая строка получает следующий номер (или номер с буквой своей группы: `S1`, `R1`, `T1`). Строка, которая перестала действовать, остаётся в таблице с пометкой «снята (решение N)».
3. **Статус — в первой строке и только про саму спеку:** черновик, рабочая версия или утверждена братом; реализовано или нет. Что проверено в редакторе, пишется в `Docs/journal.md`; что осталось проверить человеку — в `PENDING.md`.
4. **Новая спека** — по `_TEMPLATE.md`, строка в этот указатель и термины в `../glossary.md` прежде, чем появятся классы.
5. Большая новая тема — отдельный файл. Правка правила в существующей теме — в её файле.
