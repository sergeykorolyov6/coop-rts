# Механика: буры рамкой (U9)

Статус: **черновик, не реализовано.** Веха U, этап U9 (`../plan-convenience.md`). Просьба Сергея (16.11.2026): удобство как в Mindustry. Всё ниже — **решение Claude**; брат может поправить.

Месторождение — это 3–10 буров (`drill.md`), и сейчас каждый ставится отдельным кликом с прицеливанием по клеткам. Рамкой игрок обводит руду, а игра сама раскладывает буры плиткой так, чтобы под ними оказалось больше всего руды. Решение «где копать» остаётся за игроком, раскладка по клеткам — за игрой.

## Допущения

1. Правила бура и стройки — `drill.md`, `construction.md`. Состояние сима не меняется: расчёт только читает карту, заказ — обычный `BuildCommand` с несколькими местами.
2. Работает для любого здания с поведением «бур» (`behavior = drill`): бур 2×2 и малый бур 1×1 Мусорщиков. Для остальных зданий рамки нет.
3. Ленты к бурам рамка не тянет.

## A. Поведение

- **Намерение:** застроить месторождение одним движением.
- **Input:** выбран бур. Клик — один бур, как сейчас. Нажать ЛКМ, протянуть рамку хотя бы на одну клетку в сторону и отпустить — буры по всей рамке.
- **Action:**
  - рамка — прямоугольник клеток между точкой нажатия и курсором;
  - буры встают сеткой с шагом в размер бура; у сетки 2×2 четыре возможных сдвига относительно угла рамки. Выбирается сдвиг, при котором под поставленными бурами больше всего клеток руды;
  - бур ставится в ячейку сетки, если она целиком внутри рамки, на этом месте можно строить (`construction.md`) и руда занимает не меньше половины его клеток (`drill_fill_min_ore_pct`: 2 из 4 у бура 2×2, 1 из 1 у малого);
  - порядок стройки — от самого богатого бура к самому бедному; при равенстве — снизу вверх, слева направо.
- **Условия:** как у стройки бура: каждый бур оплачивается, когда строитель до него дошёл. Не больше 256 буров в одном заказе.
- **Результат:** строитель получает один заказ на все буры рамки и строит их по порядку.

## B. Данные

### Выбор сдвига

Для каждого из сдвигов (0…ширина−1, 0…высота−1) считаются поставленные буры и руда под ними. Побеждает сдвиг с наибольшей суммой клеток руды; при равенстве — тот, где буров меньше; при равенстве — с меньшим сдвигом по вертикали, потом по горизонтали.

### Параметры

| Параметр | Значение |
|---|---|
| Минимум руды под буром в рамке | 50 % клеток (`rules.csv`, `drill_fill_min_ore_pct`) |
| Буров в одном заказе | до 256 |

### Ограничения

- буры ставятся только целиком внутри рамки: за её пределами ничего не появится;
- бур с одной клеткой руды из четырёх рамка не ставит, но его по-прежнему можно поставить кликом;
- руда под буром считается, как в `DrillPreview`: по ресурсу, которого под буром больше.

### Fail cases

- в рамке нет ни одного места под бур — ничего не заказано, подсказка «в рамке нет места для бура»;
- рамка меньше одного бура — ничего не заказано.

### Edge cases

| Ситуация | Решение |
|---|---|
| Рамка 1×1 при буре 2×2 | Меньше одного бура: ничего. Нажатие и отпускание в одной клетке — обычный клик (бур с центром у курсора) |
| Руда двух видов в рамке | Каждая ячейка считается по ресурсу, которого под ней больше |
| Неровная площадка или рампа под ячейкой (`heights.md`) | Ячейка пропускается |
| Ячейка в радиусе агрессии живого лагеря | Ставится, с тем же предупреждением, что у одиночного бура |
| Ресурса хватает на часть буров | Заказаны все; строятся по мере дохода (U7), начиная с самых богатых |
| Рамка тянется за край карты | Обрезается по карте |

### Что нужно от UI и арта

- пока рамка тянется: контур рамки, силуэт каждого будущего бура с подсветкой клеток руды под ним; ячейки, пропущенные из-за бедной руды, — жёлтым контуром, занятые — красным;
- подсказка: «Буров: N · руды под ними: R · добыча ≈ X ед./с · цена C» и, если ресурса меньше, «хватает на K»;
- подсказка у курсора до нажатия: «Клик — один бур · протяните — буры рамкой».
