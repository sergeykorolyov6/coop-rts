## Допущения

1. Виды местности и символы на карте — `terrain.csv` (этап T2): земля, вечная скала `#`, мягкая `%`, твёрдая `@`, рудная `R`, кристальная `C`. Здесь им добавляются прочность и то, что внутри.
2. Высоты — `heights.md`. Порода стоит на своём уровне; копать её можно только рядом по высоте, как и всё остальное.
3. Порода — клетка карты, не здание и не юнит: у неё нет владельца, её не выбирают и не атакуют.
4. Шахтёр — обычный юнит: производится на заводе, ходит, погибает. Боя у него нет.

## A. Поведение

- **Намерение:** открыть ход, карман или руду за стеной — тем, кто готов вложить время шахтёра.
- **Input:** выделить шахтёров, ПКМ по клетке разрушаемой породы. Shift — в очередь (`order-queue.md`).
- **Action:** каждый шахтёр прокладывает **ход** к этой клетке: находит путь от места, где стоит, до неё, на котором надо выкопать меньше всего клеток породы, и копает эти клетки по порядку, от ближней к дальней, последней — выбранную. По ходу он подходит к очередной клетке и копает её, стоя рядом.
- **Условия:**
  - при приказе: клетка разведана командой и это разрушаемая порода; среди выделенных есть шахтёр. Ход идёт по земле (шагами, как ходят юниты) и по разрушаемой породе (только через стороны клеток, не по диагонали); вечная скала и обрыв без рампы его не пропускают. Хода нет — отказ;
  - в ходе не больше 32 клеток породы — остальные игрок даёт следующим приказом;
  - копать клетку можно, стоя от неё не дальше `interact_range` и рядом по высоте (`heights.md`);
  - очередная клетка уже выкопана (другим шахтёром) — шахтёр сразу переходит к следующей; к клетке не подойти — пропускает её.
- **Результат:** клетка с прочностью 0 становится землёй того же уровня: по ней ходят, на ней строят, сквозь неё видно. Под рудной породой открывается клетка основной руды, под кристальной — второго ресурса: её берут буром или вручную (`drill.md`, `manual-mining.md`).

### Обзор

**Любая непроходимая порода закрывает обзор** — и разрушаемая (ответ брата 98), и вечная скала (решение Claude 111). Сама клетка породы видна, клетки за ней — нет, пока к ним нет прямой линии через открытые клетки. Правило одно для юнитов, зданий, маяка и крипов. Высоты (`heights.md`) действуют вместе с ним: клетка видна, если её видно и по высоте, и по линии.

Как считается линия: для клетки, сдвинутой от клетки смотрящего на (dx, dy), предыдущая клетка линии — та, что на шаг ближе к смотрящему по прямой (сдвиг × (n − 1) / n с округлением, n = max(|dx|, |dy|)). Клетка видна, если видна предыдущая и предыдущая — не порода.

### Кто не копает

- Оружие породу не ломает: ни юниты, ни турели, ни способности (решение Claude 112) — иначе осада отменила бы рельеф.
- Легион не копает (ответ брата 99). Ход, который открыла команда, открыт и для его волн: путь пересчитывается сам.
- Строитель и остальные юниты не копают — только шахтёр (тег `digger`).

## B. Данные

### Состояния клетки

```
Порода (прочность = максимум) ──(шахтёр копает)──▶ Порода (прочность меньше)
        └──────────────────────────────(прочность 0)──────────────────────▶ Земля / руда
```

Обратно порода не зарастает, недокопанная клетка прочность не восстанавливает.

### Параметры (числа условные, для настройки)

| Порода | Символ | Прочность | Одним шахтёром | Внутри |
|---|---|---|---|---|
| Вечная скала | `#` | — | не копается | — |
| Мягкая | `%` | 100 | 5 с | — |
| Твёрдая | `@` | 400 | 20 с | — |
| Рудная | `R` | 200 | 10 с | основная руда |
| Кристальная | `C` | 300 | 15 с | второй ресурс |

| Шахтёр (`miner`) | |
|---|---|
| Прочность, броня | 140, 1 |
| Атака | нет |
| Скорость, обзор | 2,4 клетки/с, 6 клеток |
| Цена, производство | 30 основного, 15 с, на заводе каждой фракции |
| Копание | 20 прочности в секунду; несколько шахтёров на одной клетке складываются |

Прочность и «внутри» — колонки `hp`, `ore` в `terrain.csv`; копание — колонка `dig_rate` в `units.csv` (прочности в секунду).

### Ограничения

- Копать может любой игрок команды; выкопанная клетка ничья.
- Новая клетка руды присоединяется к соседнему (по стороне) месторождению того же ресурса с наименьшим номером, иначе становится новым месторождением (решение Claude 113). Два месторождения при этом не сливаются.
- Порода, которую видно, может быть ещё не разведана целиком — копать можно только разведанную клетку.

### Fail cases

- в выделении нет шахтёра — отказ «Нет шахтёра», ничего не начато;
- клетка не разведана — отказ «Место не разведано»;
- клетка — не разрушаемая порода (вечная скала, земля, здание) — отказ «Нечего копать»;
- до клетки не прокопать (кругом вечная скала или обрыв) — отказ «Не прокопать: мешает скала»;
- очередь шахтёра полна — как у любого приказа (`order-queue.md`).

## C. Проверка

Во всех строках, если не сказано иное: карта на уровне 0, шахтёр стоит на земле вплотную к породе.

### Edge cases

| Ситуация | Решение |
|---|---|
| Клетку докопал другой шахтёр, пока этот шёл | Этот сразу берётся за следующую клетку хода |
| Шахтёр погиб посреди клетки | Прочность клетки остаётся сниженной |
| Ход длиннее 32 клеток | Копает первые 32, дальше — новый приказ |
| Рудная порода касается двух месторождений | Клетка — месторождению с меньшим номером, они не сливаются |
| Выкопана клетка возле лагеря крипов | Крипы теперь видят через пролом и поднимаются на тех, кто в радиусе |
| Атака по породе | Невозможна: порода — не цель |
| Ход по диагонали между двумя клетками породы | Нет: по породе ход идёт только через стороны, иначе выкопанная клетка не соединилась бы с соседней |
| Приказ группе шахтёров с разных сторон стены | Каждый прокладывает свой ход от своего места: шахтёр с дальней стороны прокапывает стену насквозь до выбранной клетки |
| Шахтёр копает, враг рядом | Продолжает копать: боя у шахтёра нет, увести — приказом |
| Здание у самой породы | Ничего не меняется: копают клетку, не здание |
| Обзор над стеной с высоты | Стена закрывает и с плато: линия идёт через клетку породы |

### Что нужно от UI и арта

- шахтёр на заводе каждой фракции, свой силуэт (бур спереди);
- ПКМ по разрушаемой породе с шахтёром в выделении — курсор «копать», подсказка «прокопать ход: N клеток»; Shift — в очередь;

- выкапываемая клетка темнеет и оседает по мере прочности;
- выкопанная клетка исчезает, на её месте земля или руда; ход сразу виден на миникарте;
- подсказка при наведении на породу: вид, прочность, «копает шахтёр»;
- тексты отказов: «Нет шахтёра», «Нечего копать», «Не прокопать: мешает скала».

## Приложение: перевод в единицы Sim

- `terrain.csv` → `TerrainStats.Hp`, `TerrainStats.OreType`; `units.csv` `dig_rate` → `UnitStats.DigPerTick` (20 в секунду = 1 за тик, дробь — ошибка конвертера); тег `digger`.
- `MapState`: прочность клеток, `RockHp`, `IsOpaque`, `DamageRock` (клетка → земля, руда → месторождение, `Version++`), `RockChecksum` — свёртка прочностей для `StateHash`, обновляется при каждом ударе.
- `DigCommand` (id 14), `UnitOrderKind.Dig`, `Digging.PlanTunnel` (поиск 0-1: шаг по земле — 0, клетка породы — 1), `Digging.TickDig`.
- `FogOfWar`: линия обзора через таблицу «предыдущих клеток»; `Sight.LineOfSight` — для крипов.
- Событие `RockDestroyed`; отказы `NoDigger`, `NothingToDig`, `CannotDig`.
- Тесты — `Game.Sim.Tests/Mechanics/TerrainTests.cs`.
