Статус: **реализовано (16.11.2026)**; что проверено в редакторе — `Docs/journal.md`, веха U. Веха U, этап U8 (`../plan-convenience.md`). Просьба Сергея (16.11.2026): удобство как в Mindustry. Всё ниже — **решение Claude** по образцу SC2 и ИИ Легиона; брат может поправить.

Сейчас по правому клику армия идёт мимо врагов и получает урон, не отвечая: приказа «идти с боем» у игрока нет, хотя в симе он есть и им ходят волны Легиона. Привычную клавишу A занимает камера, поэтому бой по дороге становится поведением по умолчанию: боевые юниты по ПКМ идут и дерутся со всем, что видят. «Идти, не отвлекаясь» остаётся для отступления (JTBD «тактика, а не скорость кликов»; столп «микроконтроль» — для тех, кто хочет).

## A. Поведение

- **Намерение:** послать армию и не следить, отвечает ли она на врагов по дороге.
- **Input:** ПКМ по земле выделенными юнитами — «идти с боем». Ctrl + ПКМ по земле — «идти, не отвлекаясь». Shift добавляет любой из них в очередь.
- **Action:** юнит идёт к точке. Враг в его собственном обзоре — атакует: сначала юниты, потом здания, ближайший, при равенстве меньший id. Цель погибла или ушла из обзора — берёт следующую, врагов нет — идёт дальше. Дошёл — стоит и ведёт себя как простаивающий (`combat.md`).
- **Условия — кому достаётся бой:** команда приходит всем выделенным, а сим решает по юниту:

  | Юнит | Получает |
  |---|---|
  | может атаковать, не строитель и не разведчик | «идти с боем» |
  | строитель (есть `Worker`) | «идти» |
  | не может атаковать (ремонтник, шахтёр, Послушник) | «идти» |
  | с тегом `scout` | «идти» |

- **Результат:** армия, посланная через карту, не проходит мимо рейдеров у буров; разведчик и строитель не ввязываются в бой.

ПКМ по врагу, руде, трофею, повреждённому зданию — как сейчас. Если часть выделенных получает особый приказ (строитель — копать), остальные идут в эту точку с боем.

## B. Данные

### Состояния

Новых нет: `Идёт с боем ⇄ Бьёт` из `legion-ai.md`, в конце — простой.

### Ограничения

- бьёт только видимого врага (`heights.md`); неуязвимые точки интереса целями не становятся;
- за целью, ушедшей из обзора, юнит не гонится: возвращается к пути в точку;
- на удар издалека, из-за пределов своего обзора, юнит не отвечает — как простаивающий.

### Fail cases

- точка недостижима — идёт к ближайшей достижимой клетке, как при «идти»;
- очередь приказов полна (32) — приказ не добавлен, «нельзя».

### Edge cases

| Ситуация | Решение |
|---|---|
| Точка за краем карты | Обрезается по карте, как у «идти» |
| Враг на плато, юнит ближнего боя внизу, враг виден команде | Идёт к нему через рампу (`heights.md`): через обрыв ближний бой не бьёт |
| Идёт с боем мимо лагеря крипов в пределах своего обзора | Нападает на крипов: это и значит «с боем». Обойти — Ctrl + ПКМ |
| Герой Жёлтой Звезды | Идёт с боем |
| Пещерные юниты игрока | Идут с боем |
| Команду «идти с боем» получил чужой юнит | Пропущен, как в любой команде (`UnitSelection.Resolve`) |

### Что нужно от UI и арта

- метка приказа на земле: «идти с боем» — красная, «идти» — зелёная; так же в линиях очереди приказов;
- подсказка у курсора над землёй, когда выделены боевые юниты: «ПКМ — идти с боем · Ctrl — не отвлекаясь»;
- справка F1 и `hotkeys.md`: ПКМ и Ctrl + ПКМ.
