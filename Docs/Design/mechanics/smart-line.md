# Механика: умная линия (U3)

Статус: **реализовано (16.11.2026)**; что проверено в редакторе — `PLAN.md`, веха U. Решение Claude при реализации: выход моста не ставится на изгиб — он отдаёт только прямо по своей линии, и лента после изгиба стояла бы. Веха U, этап U3 (`../plan-convenience.md`). Просьба Сергея (16.11.2026): удобство как в Mindustry. Всё ниже — **решение Claude** по образцу Mindustry (линия от точки до точки, автоматические мосты через препятствия); брат может поправить.

Сейчас лента повторяет путь мыши клетка за клеткой: рука дрогнула — лишний поворот, а мост ставится отдельным инструментом в два клика. Умная линия считается от начала до курсора: прямая с одним изгибом, мост через препятствие вставляется сам, конец прилипает к зданию, которое принимает ресурс. Игрок думает «отсюда — туда», а не «клетка, клетка, поворот» (JTBD «тактика, а не скорость кликов»).

## A. Поведение

- **Намерение:** провести ленту из точки в точку одним движением.
- **Input:** выбрана лента; нажать ЛКМ на первой клетке, тянуть, отпустить на последней. R во время протягивания меняет сторону изгиба. Одна клетка без протягивания ставится как сейчас, её направление крутит R.
- **Action — форма пути:**
  - путь идёт от начала по одной оси до изгиба, потом по другой до курсора; изгиб один;
  - первой идёт ось, по которой курсор впервые ушёл с начальной клетки (если ушёл по диагонали — горизонталь); R меняет её на другую до конца протягивания;
  - длина — не больше 256 клеток (`BuildCommand.MaxSites`); дальше путь обрезается.
- **Action — что становится с каждой клеткой пути** (направление пути в клетке — к следующей клетке, у последней — от предыдущей):

  | Клетка | Что с ней |
  |---|---|
  | Свободна, строить можно | Новая лента по направлению пути |
  | Своя лента, смотрит туда же | Пропускается: уже есть |
  | Своя лента, смотрит навстречу | Перекладывается по направлению пути (U4) |
  | Своя лента поперёк пути — первая клетка | Перекладывается: игрок начал с неё |
  | Своя лента поперёк пути — последняя клетка | Путь заканчивается на клетку раньше и смотрит в неё: врезка (U2) |
  | Своя лента поперёк пути — в середине | Препятствие |
  | Скала, порода, чужая лента, любое другое здание, не разведано | Препятствие |
  | Между этой клеткой и предыдущей обрыв (ресурс не перейдёт) | Обе клетки становятся концами моста |

- **Action — препятствия:**
  - несколько препятствий подряд на прямом участке — один пролёт. Клетка пути перед пролётом становится входом моста, клетка после — выходом;
  - мост возможен, если оба конца — клетки под новую ленту и расстояние между ними не больше `bridge_range` (то есть пролёт не длиннее 3 клеток) и в пролёте нет изгиба;
  - мост невозможен — путь обрывается перед пролётом: дальше ничего не заказывается, клетки показаны красным;
  - препятствие на первой клетке — линию начать нельзя;
  - препятствия в самом конце пути отбрасываются.
- **Action — прилипание конца:** если после отбрасывания путь упирается в здание, которое принимает ресурс с ленты (свой или союзный штаб, склад, здание со складом; свой вход моста), последняя клетка смотрит в него. Проверяются направления: прямо, потом влево, потом вправо от хода пути; назад — никогда.
- **Условия:** как у любой стройки; цена — 1 за новую клетку ленты, 6 за конец моста; перекладка и пропуск бесплатны.
- **Результат:** строителю уходит список заказов в порядке пути: участок ленты, мост, участок ленты.

Для стены: каждая клетка пути, где можно строить, — стена; остальные пропускаются, путь продолжается.

## B. Данные

### Результат расчёта

Список клеток пути, у каждой — координаты, направление и вид: **новая лента, пропуск, перекладка, вход моста, выход моста, под мостом, обрыв** (заказ не дошёл: красная). Плюс цена: сколько клеток ленты и концов моста.

### Параметры

| Параметр | Значение |
|---|---|
| Изгибов | не больше одного |
| Длина пути | до 256 клеток |
| Пролёт моста | до 3 клеток между концами (`bridge_range` 4), без изгиба |

### Ограничения

- чужую ленту линия не трогает: её можно только перейти мостом (`conveyors.md`, ответ 14);
- ленту поперёк пути линия не перекладывает, кроме первой клетки: так нельзя случайно разорвать соседнюю линию;
- конец моста не ставится на существующую ленту: если клетка перед пролётом или после него уже занята своей лентой, мост невозможен.

### Fail cases

- первая клетка — препятствие: силуэт красный, отпускание ничего не заказывает;
- мост не достаёт: построится только часть до пролёта, подсказка «мост не достаёт: пролёт N клеток, дальность 3»;
- весь путь — пропуск: ничего не заказано, подсказка «лента уже есть».

### Edge cases

| Ситуация | Решение |
|---|---|
| Изгиб попадает на препятствие | Мост невозможен (в пролёте изгиб): заказ до пролёта |
| Клетка перед пролётом — своя лента вдоль пути (пропуск) | Мост невозможен: конец моста на существующую ленту не ставится. Игрок сносит клетку или ведёт линию рядом |
| Путь длиннее 256 клеток | Обрезается на 256-й |
| Неразведанная клетка в середине | Препятствие; мост через неё возможен, если концы разведаны |
| Два пролёта подряд через одну свободную клетку | Два моста: выход первого и вход второго — разные клетки, между ними должна быть хотя бы одна клетка под каждый конец; иначе второй мост невозможен |
| Линия из одной клетки | Одна лента с направлением по R; прилипание не действует |
| Последняя клетка рядом с приёмником сбоку, а прямо по ходу — свободно | Прилипает вбок: игрок остановился у здания |
| Последняя клетка рядом с двумя приёмниками | Прямо, потом влево, потом вправо |
| Строитель занят: у него непустая очередь Shift | Каждый участок встаёт в очередь отдельным приказом; при переполнении очереди (32) остаток отклонён с уведомлением |

### Что нужно от UI и арта

- силуэт пути перестраивается каждый кадр протягивания; цвета: новая лента — зелёный, пропуск — серый, перекладка — голубой, концы моста и пролёт — как в инструменте моста, обрыв заказа — красный;
- стрелка направления на каждой клетке ленты и на концах моста;
- подсказка: «Лента: N · мостов: M · цена C» и, если ресурса меньше, «хватает на K — остальное по мере дохода»; «R — изгиб с другой стороны»; причина обрыва, если он есть;
- подсказка «прилипнет к штабу / складу / заводу», когда конец прилип.
