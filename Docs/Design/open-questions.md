# Вопросы и решения геймдизайна

Как решаем (Сергей, 02.11.2026): **ответы брата → «CoopRTS v0.3.pdf» (`vision.md`) → решение Claude.** Мелкие вопросы Claude решает сам, по референсам (Mindustry, SC2 и другие RTS), и записывает сюда с пометкой «Claude» — брат может поправить любое такое решение. Брату уходит вопрос, только если без него никак: новая механика или фракция, изменение скоупа, противоречие между ответами брата и PDF. То, что есть в `PLAN.md`, но нет ни в ответах брата, ни в PDF, придумал Claude — это можно менять без вопросов. Нумерация сквозная, номера не переиспользуются.
