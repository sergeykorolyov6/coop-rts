# Горячие клавиши

Решение Сергея (05.11.2026): W, A, S, D, Q и E — только камера, команды на них не вешаем.

| Клавиша | Что делает | Где в коде |
|---|---|---|
| W A S D, стрелки, край экрана | двигать камеру | `RtsCamera` |
| Q / E | повернуть камеру | `RtsCamera` |
| колесо мыши | приблизить / отдалить (плавно) | `RtsCamera` |
| средняя кнопка | тянуть землю | `RtsCamera` |
| Space | камера к своему штабу | `RtsCamera` |
| Tab | выделить строителя (дважды — камера к нему) | `SelectionController` |
| G | выделить героя (дважды — камера) | `SelectionController` |
| 1–0, Ctrl/Shift + цифра | группы | `SelectionController` |
| F2, кнопка «Армия» над миникартой | выделить всю армию: все свои юниты, кроме строителя и ремонтников (дважды — камера к ней), как в SC2 | `SelectionController` |
| Ctrl+F1–F4 | переключить игрока (кооп на одном компьютере; в сетевой игре выключено) | `LocalPlayer` |
| Z X C V | способности выделенных юнитов по порядку | `AbilityPanel` |
| Меню стройки (выделен строитель): B — бур, N — малый бур, P — Смазчик, L — лента, M — мост, K — склад, F — завод (любой фракции), H — штаб, T — турель, Y — стена | ставить здание | `BuildMenu._hotkeys` (по id, иначе по виду модели) |
| R | повернуть здание при размещении | `PlacementController` |
| Delete | снести выделенное здание | `BuildingPanel` |
| Shift | приказ в очередь | `OrderController`, `PlacementController` |
| Esc | отменить размещение или прицел, иначе меню паузы | `PlacementController`, `AbilityPanel`, `GameMenu` |
