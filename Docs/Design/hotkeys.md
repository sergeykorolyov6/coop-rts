# Горячие клавиши

Решение Сергея (05.11.2026): W, A, S, D, Q и E — только камера, команды на них не вешаем.

| Клавиша | Что делает | Где в коде |
|---|---|---|
| W A S D, стрелки, край экрана | двигать камеру | `RtsCamera` |
| Q / E | повернуть камеру | `RtsCamera` |
| колесо мыши | приблизить / отдалить (плавно) | `RtsCamera` |
| средняя кнопка | тянуть землю | `RtsCamera` |
| Space | камера к своему штабу | `RtsCamera` |
| Tab | выделить строителя (дважды — камера к нему) | `SelectionController` |
| G | выделить героя (дважды — камера) | `SelectionController` |
| 1–0, Ctrl/Shift + цифра | группы | `SelectionController` |
| F2, кнопка «Армия» над миникартой | выделить всю армию: все свои юниты, кроме строителя и ремонтников (дважды — камера к ней), как в SC2 | `SelectionController` |
| Ctrl+F1–F4 | переключить игрока (кооп на одном компьютере; в сетевой игре выключено) | `LocalPlayer` |
| Z X C V | способности выделенных юнитов по порядку | `AbilityPanel` |
| Меню стройки (всегда, при любом выделении): B — бур, N — малый бур, P — Смазчик, L — лента, M — мост, K — склад, F — завод (любой фракции), H — штаб, T — турель, Y — стена | ставить здание; приказ уходит своему строителю, режим держится до ПКМ или Esc (`mechanics/build-mode.md`) | `BuildMenu._hotkeys` (по id, иначе по виду модели), `PlacementController` |
| R | повернуть здание при размещении; во время протягивания ленты или стены — сменить сторону изгиба линии (`mechanics/smart-line.md`) | `PlacementController` |
| Delete | снести выделенное своё здание; без него — режим сноса рамкой (ПКМ / Esc — закончить), то же — кнопка «Снос» в меню стройки (`mechanics/relay-and-demolish.md`) | `BuildingPanel`, `BuildMenu`, `PlacementController` |
| ПКМ по земле | идти с боем: боевые юниты бьют всех врагов в своём обзоре по пути; строитель, разведчик и безоружные просто идут (`mechanics/attack-move.md`) | `OrderController` |
| Ctrl (Cmd) + ПКМ по земле | идти, не отвлекаясь | `OrderController` |
| U, кнопка «Восстановить (N)» в меню стройки | все свои призраки — силуэтами своему строителю; ПКМ строителем по призраку (и союзному — за свой счёт) — восстановить один (`mechanics/rebuild-ghosts.md`) | `BuildMenu`, `OrderController` |
| Shift | приказ в очередь; при размещении здания — «после всего, что уже приказано строителю» | `OrderController`, `PlacementController` |
| Alt + левый клик по земле или по миникарте | метка для союзников (`mechanics/coop-tools.md`) | `SelectionController`, `Minimap` |
| Кнопки «+50 осн.» и «+50 втор.» у союзника под кошельком (Shift — в пять раз больше) | передать союзнику ресурс | `Hud` |
| F1 | «Как играть»: цикл игры и управление; в одиночной игре — пауза (решение Claude) | `Guide` |
| Esc | закрыть справку, отменить размещение или прицел, иначе меню паузы; в главном меню — закрыть открытый раздел | `Guide`, `PlacementController`, `AbilityPanel`, `GameMenu` |
